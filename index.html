CX Car YT

O CX Car YT é uma ferramenta pessoal de automação do canal de YouTube "CX Car". Ela cria vídeos curtos (Shorts) com histórias curiosas do mundo dos carros e os publica no canal do próprio dono da ferramenta, usando a YouTube Data API com a permissão de envio de vídeos.

CX Car YT is a personal automation tool for the "CX Car" YouTube channel. It creates short videos (Shorts) with car stories and uploads them to the tool owner's own channel using the YouTube Data API with the video upload permission.

Como funciona / How it works

  • Escolhe um tema, escreve o roteiro e monta o vídeo. / Picks a topic, writes the script and builds the video.
  • Envia o vídeo pronto ao canal do dono. / Uploads the finished video to the owner's channel.
  • Não acessa dados de outros usuários. / It does not access any other user's data.
